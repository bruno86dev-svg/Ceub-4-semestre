# Plano de Implantação — PortfolioHUB (Desafio - Entrega Final)

## 1. Planejamento da Implantação
**Objetivo:** transformar o repositório acadêmico (`Ceub-4-semestre`) em um PortfolioHUB — plataforma
centralizada para exibir e gerenciar meus projetos e portfólios digitais, com gestão de usuários e
segurança, usando Git/GitHub e apoio do Google GEMINI.

**Etapas do plano:**
1. Consolidar a arquitetura de pastas (feito na Entrega Intermediária).
2. Publicar o site via GitHub Pages (feito — `index.html` na raiz do repositório).
3. Usar o Google GEMINI como apoio para: revisar a estrutura do repositório, sugerir boas práticas de
   README e checklist de segurança, e tirar dúvidas durante a implantação (prompts registrados abaixo).
4. Configurar gestão de usuários e segurança no GitHub (ver `Seguranca_e_Acesso.md`).
5. Integrar e documentar o compartilhamento/controle de acesso do repositório.
6. Testar o PortfolioHUB publicado e revisar links antes da entrega.
7. Gravar vídeo de apresentação final (ver `Roteiro_Video_Entrega_Final.md`).

## 2. Configuração Inicial e Integração com GitHub
- Repositório dedicado ao projeto: [`Ceub-4-semestre`](https://github.com/bruno86dev-svg/Ceub-4-semestre) (público).
- GitHub Pages habilitado (branch `main`, pasta raiz) → publica automaticamente o PortfolioHUB a cada commit.
- Estrutura de pastas por disciplina/projeto, com README.md documentando cada uma.
- Armazenamento dos projetos acadêmicos centralizado neste único repositório, referenciado pelo PortfolioHUB.
